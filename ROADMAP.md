# Adaptive Learning Audit Roadmap

Phạm vi: đánh giá tĩnh repository và các lệnh build/test chạy được trong môi trường hiện tại. Trạng thái runtime của backend, database, provider bên ngoài và BKT chưa được xác minh. Các ưu tiên P0-P3 là thứ tự xử lý đề xuất; không có giá trị credential nào được ghi ở đây.

## Trạng thái chức năng

| Chức năng | Đánh giá | Bằng chứng và giới hạn |
|---|---|---|
| Auth, signup/email verification, Google login | Đã triển khai trong source; runtime một phần chưa xác minh | `module/users` có controller/service/mapper và frontend auth screens/services; cần SMTP/Google config và runtime tests. |
| Certificate/topic/question catalog, exam/template | Đã triển khai trong source | Có entity/repository/service/controller và admin/user screens; chưa kiểm thử API end-to-end. |
| Attempt lifecycle, save/submit/result/history | Đã triển khai trong source, chưa xác minh runtime | Có controller/service/entity/repository và UI thi; thiếu attempt integration tests và xác minh race/expiry. |
| Billing, payment history, entitlements/webhooks | Đã triển khai trong source; provider runtime chưa xác minh | Có strategies, webhook/event handling, entitlement service và UI; test hiện có chủ yếu ở service. |
| Analytics/progress/recommendations | Đã triển khai trong source; tích hợp UI/API chưa xác minh | Có service/repositories/controller/tests và màn hình tiến độ/admin. |
| Adaptive/BKT | Triển khai một phần | Có heuristic, client Java và Python endpoint; chưa chạy được Python hoặc kiểm chứng hiệu chuẩn trên dữ liệu thực. |
| AI grading/jobs, content generation | Triển khai một phần | Có provider, persisted jobs, service/controller và admin screen; scheduler/trigger và luồng pending-to-terminal chưa được chứng minh. |
| Tutor | Triển khai một phần | Có conversation/message persistence, controller/service và màn hình; gọi provider, giới hạn và chất lượng chưa được xác minh runtime. |
| RAG/PDF knowledge base | Triển khai một phần | Có upload/search/chunk/PDF extraction và admin UI; retrieval là tìm kiếm token trong source, chưa thấy vector retrieval hoặc đánh giá chất lượng. |
| Speaking | Triển khai một phần | Có submission/evaluation API, entity/service; không đủ bằng chứng về audio/STT và luồng chấm hoàn chỉnh. |
| Study planner | Triển khai một phần | Có CRUD/task/summary service và UI; chưa chứng minh tạo lịch thông minh/AI hoặc test tích hợp. |
| Frontend build | Đã xác minh build | `npm run build` thành công; đây không phải kiểm thử runtime/API. |
| Backend, database và external integrations | Chưa xác minh runtime | Thiếu Java trong môi trường audit; không chạy DB, Docker hoặc provider. |

## Build và chạy

- Backend yêu cầu JDK 17 và Gradle Wrapper: từ `Adaptive Learning/`, chạy `./gradlew.bat test`, `./gradlew.bat build`, hoặc `./gradlew.bat bootRun`. Backend cần MySQL theo datasource config; tích hợp email/Google/AI/payment cần cấu hình tương ứng. Port mặc định trong local profile là 9090.
- Frontend yêu cầu Node.js/npm: từ `AdaptiveLearningFE/`, chạy `npm ci`, `npm run dev`, hoặc `npm run build`. Frontend cần `VITE_API_KEY` trỏ tới API; Google login cần client ID nếu bật.
- BKT yêu cầu Python 3.10 theo Dockerfile và package `pyBKT==1.4.3`: từ `Adaptive Learning/pybkt/`, cài `requirements.txt`, sau đó chạy `python app.py`. Mặc định port 8001; endpoint health là `/health`.
- Docker Compose định nghĩa MySQL, backend, frontend và pyBKT. Cần Docker Compose và cấu hình môi trường an toàn; cần review các default values trước khi dùng ngoài local.

## Kiểm tra đã thực hiện

- `npm run build` trong `AdaptiveLearningFE/`: thành công.
- `./gradlew.bat test` trong `Adaptive Learning/`: không chạy được do thiếu Java/JAVA_HOME; không phải kết quả test pass/fail.
- `python --version`, `python -m py_compile pybkt/app.py`, `python -m pip show pyBKT numpy scipy`: không chạy được vì Python không có trong PATH.
- Kiểm kê source/config bằng `rg --files`, `rg -n`, `Get-Content` và kiểm tra worktree bằng `git status --short`. Không chạy Docker, không gọi DB hoặc external providers.
